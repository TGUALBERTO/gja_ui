# Spec Delta

## REMOVED Requirements

### Requirement: [API] Propriedades
**Reason**: `GjaIconButton` passa a ser o `GjaButton` só com ícone, como o `sap.m.Button` com `icon` e `tooltip`.
**Migration**: Use `GjaButton(icon: …, tooltip: …, onPress: …)`; `onPressed` passa a `onPress`, o desabilitado passa a `enabled: false`, e o tipo padrão passa a `standard` (passe `type: GjaButtonType.transparent` numa barra).
